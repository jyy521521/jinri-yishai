# 《今日宜晒》P1b 核心玩法重构 · 2026-11-20

## 重构原因
用户体验反馈：P1a “感觉有点难玩，不好玩”。P1a 的九宫格、行动点、五个工具和精确干度造成高理解门槛，核心反馈又太弱。本批次停止堆新系统，先让玩家在 60 秒内体验到直观乐趣。

## 保留
二十四节气、国风纸雕小院、萝卜干与柿饼等晒秋题材、天气变化、品质与院落成长、免费与纯激励广告商业目标。

## 取消 / 延后
P1b 不再提供九宫格、手动挪竹匾、逐时辰推演、三行动点、压石头、复杂特性标签。这些留在 Claude v0.1 备查，不应作为新版新手玩法恢复。

## 已实现规则
- 70 秒一局，三个自动补货的晒物竹匾。
- 竹匾干度会随真实时间增长，达到 64–87% 就出现绿色高亮并标注“刚刚好！点我”。
- 轻点收成：完美得基础分；连续三次提高倍率，第五次额外获得 65 分。早收不扣分、晚收仍有 12 分。
- 长时间无人收成会自动换下一匾，不奖励分数和收成次数（防挂机刷成长）。
- 第 20 秒和 44 秒附近出现乌云提前预警；玩家可主动开雨棚，保护所有晒物，每局 2 次；未开启仅损失一点干度，不会卡关。
- 本局得分、最长连击、累计有效收成、历史纪录、本地存档。
- 累计有效收成达到 12 件解锁辣椒；30 件解锁玉米，20/45/75 件逐步升级庭院景物。
- 支持暂停、开关提示音、手机触摸；素材由内联 SVG/CSS 绘制，无第三方游戏图片。
- 广告未接入。没有微信 SDK、充值系统、好友榜。

## 推荐体验验收
- 不阅读长教程，从首页点“开始”，5–7 秒内能看到绿色竹匾。
- 在第一个绿色状态内轻点能正确收成，且听到声音、出现漂浮得分。
- 连续三次完美收获时倍率生效；第五次增加奖励分。
- 雨前出现明显倒计时，可点击雨棚；没点也不会失败。
- 70 秒后完整结算；再玩和回小院均正常。
- 320 和 390 CSS 像素宽度不会横向溢出。
- 通过本地 Playwright 测试；发布后继续检查 HTTPS localStorage 重载与 iPhone Safari。

## 后续重点
P1c：正式美术资产（不依赖 emoji）、更好的天气过渡、产品音效；首轮真人试玩收集上手时间、首局完成率、第二局主动开启率，再决定是否继续放大投入。留存和商业效果尚未验证。

## 版本基线
P1b 作为新的主玩法。P1a 保存在 Git 历史提交中，不另存第二份活跃源码，避免双维护。
