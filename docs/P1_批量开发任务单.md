# 《今日宜晒》P1 批量开发任务单

主控文档：`今日宜晒_游戏开发总控文档_v1.0.md`。

## 第一批：玩法纵切（独立浏览器运行）

- [ ] 独立规则内核：状态、行动、天气结算、品级、固定种子、测试。
- [ ] 首页与关卡页面，1个小院、两种晒物、至少三种天气、六时辰。
- [ ] “选物品→选格子→摆放→推进→收取→结算”可玩闭环。
- [ ] 所有按钮可用；无死链；本地存档与重开。
- [ ] 原创统一 SVG 占位资源；不使用网上已有游戏图标。
- [ ] 提供单文件 HTML 和工程包；附实际运行截图及控制台错误检测。

## 第二批：策略深度

- [ ] 完整五动作：摆、移、盖、收、压；AP/限制/动画。
- [ ] 六种天气 + 3种物品特性与对应可视反馈。
- [ ] 完整5关教学+日落星级+一次试玩结束后的“再玩一次”。
- [ ] 真实天气和预报分离；同种子可复现。
- [ ] 数值黄金测试[52,26] + 固定种子模拟。

## 第三批：美术与手感

- [ ] 首页主视觉、院子分层、竹匾和晒物四状态、天气人格图标。
- [ ] 转场/放置/晒干/淋雨/抢收/结算动画及可静音音效。
- [ ] 320–430px宽真机UI检查、手指误触回归、低端机性能检查。
- [ ] 外部资产商用许可逐条审核，图标48px可读性测试。

## 第四批：成长期/广告隔离

- [ ] 本地铜钱+最小1项院落外观升级+保存。
- [ ] 模拟广告完整流程（明确注明模拟，不奖励排行榜分）。
- [ ] 事件埋点适配（本地日志即可）；玩家测试问卷与录屏反馈表。
- [ ] 工程为微信小游戏适配保留 platform 目录，但不直接假装 H5 可以上架。

## 每次交付必须包含

1. 可以直接玩的 URL 或确切的 HTML 文件。
2. 本次实现功能、未实现功能、错误修复说明。
3. 能复现的测试命令/检查结果。
4. 手机纵屏截图 + 操作状态截图。
5. 版本号、Changelog、下一批任务，不用每个按钮改完就交一次。

## 通过条件

- 第一批：点击放置成功→天气推进→收取→结算，有真实行为反馈。
- 第二批：与总控文档测试 T01–T10 一致。
- 第三批：用户仅看画面可辨别“太阳/晒物/可收”，玩家操作无需读大段说明。
- 第四批：广告异常/本地重载不使游戏卡死、不篡改排名。
