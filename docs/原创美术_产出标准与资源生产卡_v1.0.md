# 《今日宜晒》原创美术产出标准与资源生产卡 v1.0

本文件供 ChatGPT 负责原画 / UI / 图标设计时使用，也供 Claude/Codex 集成时参考。**原图必须原创输出，不使用网络游戏截图当正式资源。** 当前工程包中的 `art/今日宜晒_原创图标母版.svg` 为第一批原创图标试做（并非最终批准商用的定稿）；P1a HTML 场景图和道具 SVG 是开发阶段统一风格占位。

## 美术风格统一词

- 类型：清新国风童书、暖绘纸雕、柔软矢量感、细微宣纸肌理、有层次的小院盆景；不写实、不3D塑料、不二次元大头。
- 主色：奶油白 `#F7F0DE`、柿子橙 `#E8794F`、竹青 `#5F8F70`、天青 `#B9DCE0`、麦穗金 `#E3B654`。
- 结构：场景层次清晰，大留白；物品轮廓饱满可辨；顶部光源一致；所有图标共享相同视觉笔触。
- 不要：其它现有游戏具体角色、肖像、界面复刻、复杂摄影滤镜、英文水印、AI伪中文、无边界高饱和渐变、不可读小字。

## 核心资源设计卡

### ART-001 游戏图标

- **图案**：下半部为弧形竹匾，匾内 3 枚层次错开的柿饼，上半部是简洁灰青色屋檐与暖金太阳。
- **剪影测试**：在64×64尺寸仍能看到“太阳 / 房子 / 竹匾”；不能靠文字识别游戏；尽量避开细碎装饰。
- **制作标记**：本工程已提供 SVG+PNG 试做，未来可继续优化圆润程度、屋檐比例和品牌识别性。

### ART-002 首页小院插画

- **画面**：晨光从右上照入，青瓦白墙的中国乡村小院，院前几只饱满的圆竹匾晒着橙红柿饼、米白萝卜条；左前景少量竹叶、院墙上的淡淡树影，风铃下垂；没有人物占据正中。
- **构图**：竖屏基底，主建筑中部偏上，竹匾在中下区，预留正上方30%做标题；背景与前景必须可分离，手机UI不遮挡主体。
- **氛围**：清晨、宁静、温柔、稍微俏皮；纸绘轮廓清晰；阳光柔和而非照片写实。
- **禁忌**：不要照搬已有游戏的房屋、场景布局；不要生成任何文字，文字由程序叠加。

### ART-003 游戏院落场景

- **画面**：约35°俯视小院，前景简化，九宫格中央可读取；院墙瓦片、少量竹子/盆景放到棋盘外围；屋檐明确对应特定格。
- **技术**：无论素材绘画透视怎样，真实点击判定永远使用独立 3×3 命中网格；界面反馈层始终覆盖在格子底片之上。
- **变天差分**：晴(暖光层)、阴(凉色轻云影)、雨(雨线粒子+地面水纹)、傍晚(橙金)；不是重画4张完全不同角度的图。

### ART-005/006 晒物四状态

- **潮湿**：颜色鲜润，有轻微水珠；轮廓柔软；不让玩家误以为腐坏。
- **刚好**：质感变得微卷、颜色饱满、橙金高光，只用适量粒子强调。
- **过晒**：边缘微焦、收缩；与“霉变”的视觉区别明显。
- **霉变**：少量柔和灰绿色斑点，避免过于恶心或真实疾病联想。
- **每个状态**：同一位置、同一角度、同一竹匾尺寸，仅内容物形态变化；严禁重新随机生成导致换镜头或换物品外观。

### ART-008 天气角色剪影

- **阿日**：扁圆浅金太阳，短芒、浅笑，脸不超过太阳内圆的35%；不同表情不改基本轮廓。
- **云朵团子**：三大团白棉云，底部较平，困倦/藏太阳/飘走表情。
- **风婆婆**：竹青螺旋线型剪影，卷发像小旋风，表情顽皮不吓人。
- **雨娃**：浅雨青水滴头、短斗笠、圆眼；雨线是独立层，保持可看清。

### ART-009 五动作图标

- `place`：竹匾从手中落到地面；`move`：竹匾与一组小脚印；`cover`：竹罩罩住竹匾；`collect`：屋门内收一个竹匾；`press`：圆鹅卵石压住竹匾边。
- 同一套质感、光源、粗细、圆角；用中性深墨轮廓；触控48px可辨；不得混入系统Emoji替代成品。

## 生成、加工和验收程序

1. 先做单枚**风格锚点**（图标 + 一件柿饼 + 一段瓦檐），用户确认其可爱程度和精致度。
2. 所有资产用锚点明确轮廓、材质、光源、尺寸，**不直接用一次随机出图拼出全部场景**。
3. 对 AI 输出逐张检查：形体、文字错误、透明边缘、影子方向、尺寸与可读性；有缺陷应重绘或手工修正。
4. 需要动作的物件预先拆层（柿饼与竹匾、人物眼睛嘴巴、屋檐与雨线）避免后续只能整张抖动。
5. 每张记录：`assetId`、制作时间、生成/绘制说明、工具版本、修订、商业授权核验状态、终版文件名。上线前另做名称、角色近似和授权复核。
6. 输出压缩版 WebP/PNG 用于浏览器与小游戏；**可编辑 SVG/分层母版永久保留**。

## UI 精修验收

- 首页5秒可读懂「天气+晒场+开始」，不出现超过2个同等强调的按钮。
- 场景第一眼是国风小院，不是网页管理后台；游戏格子可触且不被美术遮挡。
- 时辰、阳光、雨点、收货、干度五种状态可以“只看动画”理解。
- 图标48px可识别；主文字≥14px，说明≥12px；阴/雨也有足够对比度。
- 晒物四状态在**缩小至80px**后仍有清晰区分。
- 原图、素材授权、制作记录齐全，未合规就只能作为内部原型使用。
